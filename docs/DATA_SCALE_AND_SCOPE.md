数据快照：2026-07-24

文档类型：派生数据背景参考

权威来源：`data/metadata/release-metadata.json`、`data/metadata/global-recovery-summary.json`、正式 JSONL 和发布 manifest

本页用于解释项目中各组数字分别代表什么，以及 4,643 条海外或地域不明线索处理到了什么程度。它方便人阅读，但不是新的权威数据层；与底层数据冲突时，以 schema、manifest、正式 JSONL 和验证器结果为准。

## 一句话总览

```text

→ 其中 4,643 条 Other/Global/Unknown 线索完成本轮裁决
```

## 10. 是否已经找出了 4,643 条线索中的所有岗位

结论分四层：

1. **处理覆盖率：是，100%。**

   4,643 / 4,643 条冻结线索都有唯一终态，没有漏处理、删除失败样本或改变分母。

2. **已经拥有精确官方岗位定位的候选：覆盖较高，但不是 100%。**

   527 个精确候选全部进入预注册网络批次，但其中存在岗位已下线、招聘板失败和页面没有岗位事实的情况。

3. **4,643 条线索中潜在可恢复的所有岗位：不能声称已经找全。**

   仍有 1,372 条信息不具体、819 条受认证或访问限制、81 条来源不可用或变化、172 条地域未解决。终态完整不等于潜在岗位召回率为 100%。

4. **全球市场中的全部 Agent 岗位：明确没有找全。**

   本轮只处理 Cycle 213 的冻结线索，没有恢复全市场发现，也没有持续扫描所有公司和招聘平台。

所以，准确表述是：

> 已经完成 4,643 条冻结线索的全量裁决，并恢复了其中当前证据足以支持的岗位；没有证据证明已经找出这些线索背后的所有潜在岗位，更不代表全球市场完整。

## 12. 推荐的持续扩展方式

下一轮不应重新逐条浏览 4,643 个来源，而应继续使用分层方式：

```text
官方新岗位信号或 TTL 到期
→ URL、域名、公司和招聘板去重
→ 结构化 ATS 批量读取
→ 确定性标题、定位、组织、重复和 Current 门
→ 只把冲突、认证和异常交给 Agent
→ 高概率与 Current 分层发布
→ 写入复核队列
```

建议顺序：

1. 95 个全球高概率岗位升级已完成，后续只对 2 个保留项做新信号触发复核；
2. 接下来处理 371 条高信号未恢复 Evidence；
3. 再按组织批处理 323 条官方招聘线索；
4. 对 819 条受阻来源实行认证收益预算；
5. 非岗位和第三方线索只由新信号触发，不做周期性全量重查；
6. 另建“新市场发现”流程持续吸收不在 7,217 条冻结证据中的新岗位。
