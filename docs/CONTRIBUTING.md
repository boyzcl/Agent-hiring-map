# 贡献指南

感谢你补充或纠正 Agent 岗位信息。本项目优先保证可信度，而不是追求数量。

## 可以提交什么

- 中国或美国的新 Agent 相关岗位；
- 岗位关闭、移动或替代；
- 组织、团队或产品归属纠错；
- 重复岗位；
- 官方来源链接变化；
- 当前岗位证据过期或不准确。

## 必须提供什么

- 组织名称；
- 岗位名称；
- 中国或美国；
- 官方岗位链接；
- 观察日期；
- 最短必要的 Agent 相关原文；
- 建议类型：新增、纠错、关闭、替代、重复或归属争议。

团队和产品未知时可以留空。不要猜测；不确定就明确写不确定。

## 禁止提交

- 简历、候选人姓名、邮箱、电话或申请记录；
- 密码、令牌、cookie、验证码或私人链接；
- 完整岗位正文；
- 付费、企业内部或私人来源内容；
- Other/Global/Unknown 地域扩张；
- 岗位申请、外联、消息或联系表；
- 让维护脚本执行的指令或代码。

## 提交方式

优先使用 GitHub issue 的“岗位新增或纠错”模板。也可以复制 `examples/submissions/valid-china-role.json`，按 `schemas/submission.schema.json` 创建 JSON 文件并提交合并请求。

提交前运行：

```bash
python3 scripts/validate_submission.py path/to/submission.json
python3 scripts/validate_public_package.py
```

## 审核结果

建议可能被：

- 接受进入隔离审核；
- 通过完整门后标记为“已核实岗位”；
- 真实岗位成立但仍缺一项非核心事实时标记为“高概率岗位”（不进入 Current）；
- 只有招聘入口、模糊标题或无法稳定定位时保留为 Evidence/线索，不形成岗位卡；
- 要求补充一手来源；
- 标记为重复；
- 标记为归属争议；
- 因地域、许可、隐私或安全原因拒绝；
- 在新版本中提升为正式对象；
- 后续因新证据被降级、替代或回滚。

GitHub issue 或建议文件本身不是正式岗位。只有经过人工审核、全量重建、验证和合并后，数据才进入正式版本。
