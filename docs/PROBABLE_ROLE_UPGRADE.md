每个升级项必须同时满足：

1. 官方具体岗位页或官方公开岗位接口；
2. 结构化标题与冻结标题一致；
3. 同一岗位正文有最短岗位级 Agent 证据；
4. 当前观察状态为公开、可访问、未关闭；
5. 无组织冲突、重复、替代、认证或私人来源问题。

19 条未调参留出中，18 条通过升级门，1 条意向登记被非岗位空缺规则正确拦截；升级门错误为 0。全部 95 条的标题和 URL 错配为 0。
