# 方法和限制

本仓库来自“中国 + 美国 Agent Hiring Map P0–P3 v1”公开来源有界验证。

P0–P3 验证了：

- 证据字段与发布边界；
- Organization、Team、Product、Role、Relation 的标准化；
- Current Opportunity 与 Evidence Ledger 的严格分离；
- 三臂检索基准；
- 离线 freshness/claim 状态机；
- 对抗、决定性重放、幂等、回滚和替代。

本公开版本没有恢复新的全球市场发现，也没有重新调查全部 7,217 条证据。它对 Cycle 213 中剩余 4,643 条 Other/Global/Unknown 冻结线索做了有界恢复，公开包仍是封存输入和受控公开来源复核的安全派生快照。

## 岗位标题真实性与双语显示

公开 Role 只有一套权威记录。每条 Role 先判断官方标题、来源粒度、稳定岗位定位、引用支持和观察日期，再生成中文和英文显示。岗位类别与职责关键词不能拼接或替代岗位标题；无法证明标题的记录只保留在 Evidence/线索层，不再显示为岗位卡。

2026-07-24 的存量恢复覆盖 1,148 / 1,148 条旧 Role 和 1,134 / 1,134 条尚未形成 Role 的中美 Evidence。旧 Role 中 703 条通过岗位列表门，445 条降级回 Evidence/线索；公开投影又按“相同官方 URL + 相同稳定定位 + 相同标题”消除 2 条重复卡片，不合并组织、不删除 Evidence。结构化招聘系统、官方岗位接口、JSON-LD 和冻结 C4 精确岗位信号恢复 265 条高概率岗位。公开观察只保存标题、状态、最短必要引文、哈希和定位信息，不保存完整招聘正文。

恢复流水线先按 URL、域名、公司和招聘系统批量去重，再运行来源适配器和确定性规则；Agent 只处理冲突、异常和机器无法判断的候选。全球批次仅对 527 个精确岗位 URL 触发公开来源复核，按 251 个来源板去重；4,643 / 4,643 条线索最终获得唯一终态，不删除失败样本、不改分母或阈值。

## 已核实、高概率与 Current

- 已核实岗位：完整通过官方标题、组织、稳定岗位定位和 Agent 相关性门；
- 高概率岗位：真实岗位和标题可信，但仍缺一项非核心事实，页面明确标注；
- 待追溯线索：只保留在 Evidence 和恢复终态账本，不形成公开岗位卡；
- 严格 Current：只从已核实岗位中产生，并额外要求无需登录的公开访问、14 天期限和当前性门。

因此 7,227 条 Evidence、1,323 条岗位记录和 969 条 2026-08-06 严格 Current 是三个不同分母；Current 由全部 1,323 条唯一公开处置直接投影，旧 836 与旧 479 都不是 allowlist。全球原始恢复形成的 95 个高概率岗位在后续同岗位正文补证中获得 95/95 唯一终态：91 个先升级为已核实岗位、再独立通过严格 Current 门；1 个意向登记和 1 个已关闭岗位继续留在高概率发现层；2 个通用岗位因为当前正文没有岗位级 Agent 证据而移回线索层。高概率记录本身仍不能直接进入 Current。

中文和英文岗位标题、地点以及界面词汇在构建期由版本化目录和确定性规则生成。页面运行时不访问翻译服务，也不加载第二份岗位数据。官方原文始终保存在 `official_title_raw`；品牌、产品名和技术缩写可以保留原写法，未知机构修饰语不会被编造成岗位事实。

组织、团队和产品的官方专名可以保留原写法；Agent、AI、LLM、RAG、MCP 等通用技术缩写不强制翻译。

## 地点与办公方式

地点派生先排除招聘渠道、期限、人数、页面残片、公司地址和团队上下文。可以可靠规范化时才显示地点；否则降级为地点待复核，并进入离线复核队列。

办公方式使用单独规则：

1. 来源明确出现 remote、hybrid、远程或混合办公信号：`remote_or_hybrid`；
2. 来源明确出现 onsite、on-site、现场办公或驻场信号：`onsite + explicit_onsite`；
3. 其他情况：`onsite + default_onsite_no_remote_signal`。

第三条是用户确认的产品规则，用于避免把“未记录远程范围”误解成第三种办公方式；它不是招聘方逐条明确声明。

## 已知限制

- 地图已做全球冻结线索的有界恢复，但中国与美国仍是优先验证地区，不代表绝对全球市场完整；
- Evidence 覆盖不等于市场完整；
- 当前岗位是有期限的公开来源判断，不是招聘方保证；
- 招聘网页可能在复核后变化；
- 公开静态HTML可能只有页面壳；不能恢复具体标题时会保守降级；
- 公开引文只保留最短必要长度；
- P0–P3 的检索基准是预注册有界对照，不代表所有联网 Agent；
- P4 只是只读开源试点，不是需求、PMF 或规模化证明。
- “默认现场”可能与招聘方未公开的灵活安排不同，求职前应打开官方来源确认。

## 可信度优先

无法确认时，本项目选择降级、保持分开或进入争议，而不是强制合并或扩大当前岗位数量。
