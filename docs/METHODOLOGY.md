# 方法和限制

本仓库来自“中国 + 美国 Agent Hiring Map P0–P3 v1”公开来源有界验证。

P0–P3 验证了：

- 证据字段与发布边界；
- Organization、Team、Product、Role、Relation 的标准化；
- Current Opportunity 与 Evidence Ledger 的严格分离；
- 三臂检索基准；
- 离线 freshness/claim 状态机；
- 对抗、决定性重放、幂等、回滚和替代。

本公开版本没有恢复全球市场发现，也没有重新调查全部 7,217 条证据。公开包是封存输入的安全派生快照。

## 双语显示

公开 Role 只有一套权威记录。中文和英文岗位方向、地点以及界面词汇在构建期由版本化目录和确定性规则生成。页面运行时不访问翻译服务，也不加载第二份岗位数据。

组织、团队和产品的官方专名可以保留原写法；Agent、AI、LLM、RAG、MCP 等通用技术缩写不强制翻译。

## 地点与办公方式

地点派生先排除招聘渠道、期限、人数、页面残片、公司地址和团队上下文。可以可靠规范化时才显示地点；否则降级为地点待复核，并进入离线复核队列。

办公方式使用单独规则：

1. 来源明确出现 remote、hybrid、远程或混合办公信号：`remote_or_hybrid`；
2. 来源明确出现 onsite、on-site、现场办公或驻场信号：`onsite + explicit_onsite`；
3. 其他情况：`onsite + default_onsite_no_remote_signal`。

第三条是用户确认的产品规则，用于避免把“未记录远程范围”误解成第三种办公方式；它不是招聘方逐条明确声明。

## 已知限制

- 只对中国和美国构建标准化地图；
- Evidence 覆盖不等于市场完整；
- 当前岗位是有期限的公开来源判断，不是招聘方保证；
- 招聘网页可能在复核后变化；
- 公开引文只保留最短必要长度；
- P0–P3 的检索基准是预注册有界对照，不代表所有联网 Agent；
- P4 只是只读开源试点，不是需求、PMF 或规模化证明。
- “默认现场”可能与招聘方未公开的灵活安排不同，求职前应打开官方来源确认。

## 可信度优先

无法确认时，本项目选择降级、保持分开或进入争议，而不是强制合并或扩大当前岗位数量。
